## ✨ Features

- **Pokédex** — search and explore the original 151 Pokémon
- **Quiz** — test your knowledge with silhouette challenges
- **Retro UI** — pixel fonts, scanlines and Pokéball vibes

## 🌊 Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JS (no frameworks)
- [PokéAPI](https://pokeapi.co/) for Pokémon data
